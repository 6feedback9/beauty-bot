# 🤍 Beauty Guide — бот подписки на закрытый канал

Девочка заходит в бот → читает о Beauty Guide и FAQ → оформляет
подписку → бот выдаёт ссылку в закрытый Telegram-канал → через
30 дней доступ закрывается автоматически.

---

## Как это работает

1. Заказчица ведёт **закрытый Telegram-канал** со своими постами.
2. Бот — «вышибала на входе»: пускает в канал только после оплаты.
3. Бот помнит дату окончания подписки у каждого.
4. Раз в час бот проверяет сроки и убирает из канала тех, у кого
   подписка кончилась. Человек может вернуться, оплатив снова.

## ШАГ 1. Создать закрытый канал (делает заказчица)

1. В Telegram: создать **новый канал**, тип — **Private (приватный)**.
2. Оформить, выложить пару стартовых постов.
3. Добавить бота в **администраторы** канала. Обязательные права:
   - Пригласить пользователей по ссылке
   - Удалять / блокировать участников
4. Узнать **ID канала**: переслать любой пост из канала боту
   **@getidsbot** — он покажет ID вида `-1001234567890`.
   Минус в начале — это нормально, его тоже вписывать.

## ШАГ 2. Бот и токен

1. В @BotFather создать бота (`/newbot`), получить **токен**.

## ШАГ 3. ID заказчицы

1. Заказчица открывает @userinfobot → Start → получает свой **ID**.

## ШАГ 4. Ключи WayForPay

1. В личном кабинете WayForPay взять:
   - `merchantAccount`
   - `merchantSecretKey`

---

## ШАГ 5. Залить код на GitHub

Загрузить в репозиторий файлы: `bot.py`, `requirements.txt`, `README.md`.

## ШАГ 6. Создать сервис на Render

- New + → Web Service → подключить репозиторий
- Language: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Instance Type: Free

## ШАГ 7. Переменные окружения (Environment)

| Key             | Value                                            |
|-----------------|--------------------------------------------------|
| `BOT_TOKEN`     | токен от BotFather                               |
| `ADMIN_ID`      | ID заказчицы                                     |
| `CHANNEL_ID`    | ID закрытого канала (с минусом)                  |
| `WEBHOOK_HOST`  | адрес сервиса, напр. `https://...onrender.com`   |
| `PYTHON_VERSION`| `3.12.7`                                         |
| `WFP_MERCHANT`  | merchantAccount из WayForPay                     |
| `WFP_SECRET`    | merchantSecretKey из WayForPay                   |
| `SUB_PRICE`     | цена подписки в грн, напр. `300`                 |
| `SUB_DAYS`      | срок подписки в днях, `30`                       |

> `WEBHOOK_HOST` — точный адрес сервиса. Render показывает его
> вверху страницы сервиса; иногда он с добавочными буквами
> (`...-xxxx.onrender.com`). Бери именно тот, что показан.

## ⚠️ Про оплату WayForPay

Подключение WayForPay — отдельный этап. Пока ключи `WFP_MERCHANT` и
`WFP_SECRET` не заданы, бот работает в **тестовом режиме**: вместо
оплаты показывает кнопку «Я оплатила (тестовый режим)», которая
сразу выдаёт доступ. Это для проверки логики.

Когда ключи будут вписаны — нужно дописать формирование ссылки на
оплату и обработку подтверждения (функции `make_payment_link` и
`wayforpay_callback` в `bot.py`). Это делается по документации
WayForPay и обсуждается отдельно.

---

## ⚠️ Про бесплатный Render и базу подписок

Бот хранит подписки в файле базы `subscriptions.db`. На бесплатном
тарифе Render файловая система **сбрасывается при перезапуске** —
значит данные о подписках со временем потеряются.

Для теста это терпимо. Для реальной работы нужно одно из двух:
- перейти на платный тариф Render с постоянным диском, **или**
- подключить внешнюю базу (бесплатный PostgreSQL на Render
  или Supabase) — код под это дорабатывается.

Это важно обсудить до приёма реальных оплат.
