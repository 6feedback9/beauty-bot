# 🌿 Beauty-бот — инструкция по запуску

Бот для подбора ухода за кожей. Клиентка выбирает тариф, заполняет
анкету, присылает фото — заявка приходит заказчице в личку Telegram.

---

## Что тебе понадобится (всё бесплатно)

1. Аккаунт **Telegram** (есть)
2. Аккаунт **GitHub** — github.com
3. Аккаунт **Render** — render.com (можно войти через GitHub)

---

## ШАГ 1. Создать бота и получить токен

1. Открой в Telegram бота **@BotFather**
2. Отправь команду `/newbot`
3. Придумай имя бота (видят люди) и username (заканчивается на `bot`)
4. BotFather пришлёт **токен** — длинная строка вида `1234567890:AAH...`
5. Скопируй и сохрани — он понадобится позже

---

## ШАГ 2. Узнать ID заказчицы

Боту нужно знать, кому слать заявки.

1. Заказчица открывает бота **@userinfobot** в Telegram
2. Нажимает Start
3. Бот пришлёт её **ID** — это число (например `123456789`)
4. Сохрани это число

> Важно: заказчица должна один раз нажать `/start` в твоём боте,
> иначе Telegram не разрешит боту ей писать.

---

## ШАГ 3. Залить код на GitHub

1. Зайди на github.com, нажми **New repository**
2. Назови, например, `beauty-bot`, оставь **Public**, создай
3. На странице репозитория нажми **uploading an existing file**
4. Перетащи туда три файла: `bot.py`, `requirements.txt`, `README.md`
   (файл `.env.example` заливать НЕ нужно)
5. Нажми **Commit changes**

---

## ШАГ 4. Создать сервис на Render

1. Зайди на render.com, войди через GitHub
2. Нажми **New +** → **Web Service**
3. Выбери свой репозиторий `beauty-bot`
4. Заполни поля:
   - **Name**: `beauty-bot` (запомни — это часть будущего адреса)
   - **Region**: Frankfurt (ближе к Украине)
   - **Branch**: `main`
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: Free
5. Пока НЕ нажимай Create — сначала добавь переменные (шаг 5)

---

## ШАГ 5. Добавить переменные окружения

Прокрути вниз до раздела **Environment Variables**, добавь три штуки:

| Key            | Value                                              |
|----------------|----------------------------------------------------|
| `BOT_TOKEN`    | токен от BotFather                                 |
| `ADMIN_ID`     | ID заказчицы (число из шага 2)                     |
| `WEBHOOK_HOST` | `https://beauty-bot.onrender.com`                  |

> Адрес для `WEBHOOK_HOST` = `https://` + имя сервиса + `.onrender.com`
> Если назвала сервис не `beauty-bot`, подставь своё имя.

Теперь нажми **Create Web Service**.

---

## ШАГ 6. Проверка

1. Render минуту-две собирает проект — смотри логи на странице сервиса
2. Когда в логах появится `Webhook установлен` — бот живой
3. Открой бота в Telegram, нажми `/start` — должно появиться меню
4. Пройди анкету сама, как клиентка — заявка с фото придёт заказчице

---

## ⚠️ Про бесплатный тариф Render

Бесплатный сервис «засыпает» после 15 минут без активности.
Первое сообщение после паузы разбудит его за 30–50 секунд —
клиентка просто чуть подождёт ответа.

Когда пойдут реальные заявки — на Render можно перейти на платный
тариф (~$7/мес), тогда бот работает без пауз.

---

## Как поменять тарифы, цены или тексты

Всё редактируется в файле `bot.py`:

- **Тарифы и цены** — словарь `TARIFFS` в начале файла
- **Приветствие** — функция `cmd_start`
- **Вопросы анкеты** — функции `get_...`
- **FAQ** — функция `show_faq`

После правок залей обновлённый `bot.py` на GitHub заново —
Render сам подхватит изменения и перезапустит бота.
